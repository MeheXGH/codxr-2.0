# CODXR 2.0

A clean production-ready starting point for the CODXR 2.0 website.

## Stack

- Next.js App Router
- JavaScript / JSX
- Tailwind CSS
- GSAP for animation
- Lucide React for icons
- next-themes for light/dark mode
- No Three.js or other 3D dependency

## Routes

- /
- /about
- /services
- /services/[slug]
- /work
- /work/[slug]
- /pricing
- /blog
- /blog/[slug]
- /tools
- /contact
- /privacy-policy
- /terms

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

Dark mode:
- Background: #121212
